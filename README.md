# NowMyWork

**Work should find you.**

NowMyWork is a freelance marketplace built around matching instead of endless bidding.

## Product idea

1. A client posts a project.
2. The platform evaluates the project's skills, tech stack, budget, deadline, priority and other constraints.
3. The best eligible freelancers receive a private opportunity.
4. A suitable freelancer accepts and the project is assigned.
5. NowMyWork earns a transaction commission.

## Current stage

The repository currently contains the Next.js foundation, brand landing page, responsive design system, and a health endpoint. The marketplace, authentication, database, payments, notifications, and matching engine will be added incrementally.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Health check

`GET /api/health`
